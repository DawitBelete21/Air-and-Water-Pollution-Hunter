
# Air and Water Pollution Hunter

## Project Overview

The Air and Water Pollution Hunter is an autonomous mobile robotic system designed to monitor air pollution and environmental conditions at different locations.

The system uses gas and particulate-matter sensors to monitor pollutants such as carbon monoxide, carbon dioxide-related air quality indicators, and dust. It also uses an ultrasonic sensor for obstacle detection, GPS for location tracking, and an IMU for motion monitoring.

Sensor and location data are transmitted wirelessly to a web dashboard, allowing users to monitor environmental conditions remotely and store collected data for further analysis.

## Main Features

- Air pollution monitoring
- Particulate-matter monitoring
- GPS location tracking
- Ultrasonic obstacle detection
- IMU-based motion monitoring
- Manual and autonomous operation
- Wireless data transmission
- Web-based monitoring dashboard
- Data storage and analysis

## System Architecture

The prototype combines an Arduino-based motor controller with an ESP32-based communication and sensing system.

The vehicle can operate in both manual and autonomous modes. In autonomous mode, obstacle detection helps the vehicle navigate while collecting environmental measurements.

## Project Status

The project is currently at the prototype and testing stage. The main hardware, sensors, wireless communication, dashboard, and autonomous movement have been integrated and tested.
